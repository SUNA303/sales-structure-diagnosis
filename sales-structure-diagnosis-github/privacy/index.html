プライバシーポリシー

砂川事務所（売上構造プロデュース）は、体験セッションの予約・事前アンケートでお預かりする情報を、以下の方針で取り扱います。

お預かりする情報と利用目的

お名前、メールアドレス、予約日時、ご本人が記入した仕事内容・商品・発信先URL・相談内容を、日程の確認、体験セッションの準備と実施、関連するご連絡、お問い合わせへの対応に利用します。

アンケートに、顧客や第三者の個人情報、機密情報、パスワード等を記載しないでください。

管理と外部サービスの利用

回答・予約情報は運営者が確認し、サービス提供に必要な範囲で取り扱います。本人の同意なく回答内容を広告やお客様の声として公開することはありません。法令に基づく場合を除き、目的外の第三者提供は行いません。

日程予約にはTimeRex、アンケートにはGoogleフォーム、オンライン面談にはZoom、サイト配信にはCloudflareを利用します。各サービスでのデータの取扱いは、各社の方針もご確認ください。

  • TimeRexのプライバシーポリシー
  • Googleのプライバシーポリシー
  • Zoomのプライバシーステートメント
  • Cloudflareのプライバシーポリシー

サイト閲覧時の情報

サイト配信サービスでは、通信・不正利用対策に必要なアクセス情報が処理される場合があります。本LPは、流入元を予約ページへ引き継ぐため、URLのUTM情報や広告クリック識別子をブラウザのセッションストレージに一時保存します。お名前やメールアドレスをこの保存処理に含めることはありません。

現在、本LPからGoogle Analytics 4・Metaピクセルへの計測情報の送信は行っていません。計測サービスを導入する場合は、取扱いと案内を更新します。

情報の確認・訂正・削除、お問い合わせ

ご自身の情報の確認・訂正・削除等のご希望は、次のアンケートページ下部にある「フォームのオーナーに問い合わせる」からご連絡ください。Googleアカウントへのログインが必要です。問い合わせ時にGoogleが表示するご本人の名前・メールアドレスが運営者へ共有されます。内容とご本人との関係を確認のうえ対応します。

問い合わせ窓口のあるページを開く ↗

アンケートへの回答を送信する必要はありません。ページの一番下の「フォームのオーナーに問い合わせる」をお選びください。
