# 成果物の構成（市場調査設計シートを兼ねる）

タイトル：「〇〇さん 集客と差別化リサーチ」
作成日・作成者（砂川さん）の行のあと、1〜2文のリードで「今回決めること」と結論を先に書く。
調べ直しで更新した時は、リードの前に「更新日と変わったこと」を1〜3行。
情報を多く並べることより、砂川さんがクライアントと「次に何を試すか」を決められることを優先する。

## 章立て

1. **提案**
   - 今回決めること（1〜3つ）と、その結論
   - 決めることに合わせた表を1つ
     - 集客経路：役割（主軸／新規の入口／補助／今はやらない）｜経路｜理由
     - 訴求・販売導線・商品の入口：段階または項目｜今｜試す案｜理由
   - SNSが論点の時だけ、SNSの位置づけを1文（表の「今はやらない」と重ねない）。差別化の方向を1〜2文
   - 調べて見立てが変わった点（あれば1〜2文）
2. **お客さんが買うまでの経路と、調べた情報源**
   - 経路の仮説（知る → 比べる → 申し込む）を2〜3行
   - 表：優先して調べた情報源｜選んだ理由
3. **市場で分かったこと**
   - 広告・販売導線から確認できた事実（見た件数・確認日・対象地域。広告が見当たらない時はそのことも）
   - 顧客の声・自社データから確認できた事実（アンケート・レビュー・相談記録など）。手元に無い時は「未入手」と1行書き、確認することに回す
   - その他の市場情報（競合の数と価格帯、探し方の調査など）。表：項目｜分かったこと（数字・データの時点・対象）｜出典
   - 競合は上位10〜20件の表を別に置いてよい
   - **代替手段**：競合以外にお客さんが選んでいる手段と、選ぶ理由
4. **〇〇さん側の条件**
   - 表：条件（時間・広告費・つながり・会話への抵抗・実績と口コミ・すでにやっていること・SNS）｜分かっていること｜確認したいこと。分からないものは「不明」
   - 本人の掲載情報の食い違い（中心になる時は段落で）
5. **言えること・言えないこと**
   - 現時点で言えること（根拠の事実つき）と、まだ言えないこと（何が分かれば言えるか）
   - 【事実】【声】【推論】【仮説】の区別が分かるように書く
6. **次に試すこと（優先順に最大3つ）**
   - 表：案（経路・訴求・商品の入口・販売導線のどれか）｜何を試すか｜期間｜数えるもの｜続ける基準｜切り替える基準
   - 次に見直す日（日付）
7. **確認すること**（チェックリスト。アクセスできなかった所は「どこで・何を見るか」まで書く）
8. **出典**（実際に開いたページだけ。URL・確認日・対象地域・確認できた範囲）

## 書き方
- 1文25字〜40字程度、段落は3文まで。数字には単位と時期
- 分からないことは推測で埋めず「不明」「確認したいこと」に書く
- 広告の掲載から売上を断定しない。「売れている」と書く時は広告以外の根拠を添え、無ければ「販売成果は未確認」
- 提案はクライアントに見せても失礼にならない言い方にする（評価・上から目線にしない）
- 金銭的な事情・家庭の事情など、提案に不要な個人情報は書かない
- クライアントの呼び方は、砂川さんが会話で使った呼び方まで。フルネーム・自宅住所・連絡先は書かない。見本や実務カードに回す時は記号（A様）にする
- 使える環境なら Docs の Artifact タイプで作る。1章ずつ埋め、出典リンクは表の中に入れる
- 会話内で出す時は、1章（提案）・5章（言えること・言えないこと）・6章（次に試すこと）・7章（確認すること）・出典を出し、2〜4章は要点だけにしてよい
