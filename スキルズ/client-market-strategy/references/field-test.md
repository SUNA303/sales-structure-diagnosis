# 小さな試しの付け方

調査で分かるのは「こうなりそうだ」まで。本人の商品・価格・地域で実際に反応があるかは、試して初めて分かる。
次に試す案は**優先順に最大3つ**（集客経路だけでなく、訴求・商品の入口・販売導線の案も含めてよい）。それぞれに試しを1つ付ける。

## 試しの形（成果物にはこの5項目で書く）
| 項目 | 書くこと |
|---|---|
| 何を試すか | 1つの経路で、1つの行動（例：Googleマップの情報と写真を整え、口コミを3件お願いする） |
| 期間 | 2〜6週間（反応が遅い業種・法人は長め） |
| 数えるもの | 本人が自分で数えられるもの（問い合わせ数・予約数・プロフィールを見た数・紹介の件数など） |
| 続ける基準 | 例：4週間で問い合わせ2件以上 |
| 切り替える基準 | 例：4週間で0件なら、情報の見せ方を1回直し、それでも0件なら次の候補の経路へ |

## 決め方
- 費用と手間がいちばん小さい形にする。作り込む前に反応を確かめる（大きな制作・有料掲載・広告は、小さな試しで反応が出てから）
- 基準の数字は、その業種の相場や本人の過去の実績から置く。根拠が無い時は「仮の基準」と書き、1回目の結果で直す
- 本人が続けられる手間か（時間・会話への抵抗）を確かめる
- 期限の日付を「次に見直す日」として成果物に書く
- 受けられる枠が少ない人（例：月8枠）は、「枠が埋まり始めたら新規の入口は広げず、情報を保つだけにする」など、上限に達した時の扱いも書く

## 経路ごとの試しの例
| 経路 | 試しの例 | 数えるもの |
|---|---|---|
| 既存客・休眠客への再連絡 | 5〜10人に予約枠の案内を送る | 返信・予約の数 |
| 紹介 | 紹介元2〜3か所にお礼と紹介文を渡す | 紹介の件数 |
| 地図・口コミ | 情報と写真を整え、既存客に口コミを依頼 | 問い合わせ・経路検索・口コミ数 |
| スキル市場（ココナラ等） | 入口用の1メニューを出品 | 閲覧・相談・購入の数 |
| SNS会話 | 1日10件のコメント・返信を2週間 | 会話になった数・面談の数 |
| SNS発信 | 週3投稿を4週間、1つのテーマで | プロフィール閲覧・LINE登録・問い合わせ |
| 他人の導線 | 講座主宰者・団体1か所に登壇・コラボを打診 | 参加者数・その後の問い合わせ |
| 法人 | 知り合いの経営者3人に試行研修を打診 | 面談・試行の件数 |
| 訴求 | 同じ経路で呼びかけを2通り用意し、同じ期間・同じ相手数で出す | 反応・申込みの差 |
| 商品の入口 | 無料相談・診断・単発メニューなど入口を1つ変えて案内する | 申込み数・その後の継続 |
| 見込み客への聞き取り | 対象に近い人3〜5人に「どこで探し、何で決めたか」を聞く | 答えの共通点 |
