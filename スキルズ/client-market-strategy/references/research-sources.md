# 調べる場所と検索語（型別）

「専門の有益な情報が集まっている所」から数字を取るための一覧。
ここに無い場所も使ってよい。大事なのは、数字の出典・時期・対象を控えること。

## 全型共通

| 何を知りたいか | 見る場所 | 検索語の例 |
|---|---|---|
| お客さんが何で探し・何で決めるか | 業界調査のプレスリリース（PR TIMES・@Press・ValuePress） | 「〇〇 選ぶ 決め手 調査」「〇〇 知った きっかけ 割合」「〇〇 利用 アンケート 2025」 |
| 業種の集客の実態 | 業種別コンサル・業界メディアのコラム（船井総研など） | 「〇〇 集客 方法 実態」「〇〇 開業 集客 失敗」 |
| 地域・対象の人数 | 市区町村の統計ページ、e-Stat、人口ピラミッドのまとめサイト | 「〇〇市 年齢別人口」 |
| SNSの利用状況 | 総務省『情報通信白書』、各社のSNS利用調査 | 「SNS 利用率 年代別 調査」 |
| 広告と遷移先 | Meta広告ライブラリ、Google 広告の透明性センター、検索結果上部の広告、リンク先のLP（見方は ad-funnel-research.md） | 「〇〇市 〇〇」「〇〇 相談」で検索して広告枠を見る |
| 代替手段 | 同じ悩みの人が選ぶ別の手段（病院・セルフケア・本・無料動画・社内対応など）の価格と、選ぶ理由 | 「〇〇 どっちがいい」「〇〇 自分で」「〇〇 比較」 |
| 悩みの言葉 | Yahoo!知恵袋、Google検索の関連語、競合のQ&Aページ | 「〇〇 悩み 知恵袋」「〇〇 どこに相談」 |

データの日付・信頼度・開けない時の扱い → research-rules.md

## ブラウザで開く所（Web検索では開けない所）
Claude のブラウザ（デスクトップアプリの内蔵ブラウザ、または Chrome 拡張）が使える時は、次を開いて確認する。
使えない時は「確認したいこと」に回し、砂川さんか本人に画面を見てもらう。
- Googleマップ：本人と上位競合の口コミ数・評価・写真・営業時間・「経路」の出方
- Instagram・Threads・X：上位者のフォロワー規模・投稿頻度・プロフィールの導線（ログインが要る場合は砂川さんのログイン状態で閲覧のみ）
- Meta広告ライブラリ・Google 広告の透明性センター：同業の広告の有無・訴求・行き先・掲載時期（掲載期間は売上の証明ではない）
- Googleトレンド：検索語の増減と季節の波
- 閲覧だけにとどめる（投稿・フォロー・メッセージ送信などの操作はしない）

## 手元の資料（最初に読む）
- 2ステップアンケートの回答・セッションの文字起こし・実務カード：本人と見込み客の生の言葉、すでにやっていること、使える時間
- 前回の「集客と差別化リサーチ」：調べた日と数字（調べ直しの時は差分だけ調べる）
- 本人の数字（LINE登録数・インサイト・予約数など）と、相談・成約・失注の記録：会話や資料にあれば使い、無ければ「不明」と記録して「確認したいこと」へ
- 既存客が選んだ理由・再来店した理由・紹介した理由：どの経路が本当に効いているかの、いちばん確かな材料

## 地域型（整体・サロン・教室・出張サービスなど）

| 何を知りたいか | 見る場所 |
|---|---|
| 競合の数・価格・口コミ数 | ホットペッパービューティー、エキテン、EPARK、楽天ビューティ、業種別ポータル（教室ならストアカ・ジモティー等） |
| 上位の店の打ち出し | ポータル上位10件のキャッチ・対象・初回価格、上位店のホームページ |
| 地図での見え方 | Googleマップは直接開けないことが多い → 「〇〇市 〇〇 口コミ」の検索結果とポータルで代わりに見て、本人のGoogleマップは本人に確認 |
| SNSの効き方 | 「〇〇市 〇〇 インスタ」で検索して、SNSアカウントが出てくるか、HPとポータルだけか |
| 本人の掲載情報 | 本人の屋号でポータル・口コミサイトを検索し、住所・営業時間・評価・口コミ数を確認 |

## オンライン個人向け型（コーチ・コンサル・講座・カウンセラーなど）

| 何を知りたいか | 見る場所 |
|---|---|
| 競合の数・価格・販売実績 | ココナラ、ストアカ、MOSH、タイムチケット、note、Brain、Udemy |
| 売れている人の入口 | 上位者のプロフィール導線（SNS→LINE→無料相談 など）、販売ページの「実績」「お客様の声」 |
| SNSの効き方 | ジャンル名＋「インスタ」「Threads」で上位者のフォロワー規模。「〇〇 起業 1年 インスタ 集客」などで後発で伸びた事例があるか |
| 他人の導線を借りられる所 | 同じ見込み客を持つ講座主宰者・コミュニティ・オンラインサロン・ポッドキャスト |
| 悩みの言葉 | ココナラの依頼文・レビュー、知恵袋、noteのコメント |

## 法人向け型（研修・顧問・制作・コンサルなど）

| 何を知りたいか | 見る場所 |
|---|---|
| 企業が払っている金額 | 研修費用の実態調査（産労総合研究所など）、研修会社の料金ページ、比較サイト |
| 企業が発注先を探す方法 | 研修・コンサルの比較サイト、自治体・公的機関の研修委託の公募、業界団体・商工会議所のセミナー |
| 競合の打ち出し | 同じテーマの研修会社の上位10社のキャッチ・対象（業種・階層）・実績の見せ方 |
| 入口になりやすい所 | 前職・知人経由の紹介、商工会議所・業界団体、ビザスクなどのスポット相談、セミナー登壇 |

企業が研修・外注先を何で探しているかの新しい調査は見つかりにくい。見つからなければ、本人の知り合いの経営者1〜2人に「頼むとしたらどこで探して何で決めるか」を聞くことを確認事項にする。
会社の規模別に外部研修の実施率が分かる調査（厚生労働省『能力開発基本調査』、JILPTの調査）は、狙う会社の規模を決める材料になる。

法人向けでは、SNSは「会社名を検索された時に信頼を確認される場所」になることが多い。
最初の1社は紹介・既存のつながりから取るケースが多いので、本人のつながりの棚卸しを先に厚くする。
