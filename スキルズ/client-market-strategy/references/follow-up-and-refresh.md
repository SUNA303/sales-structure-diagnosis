# 答え合わせと調べ直し（市場の変化への対応）

市場は変わり続ける。1回の調査を正解として持ち続けず、**日付をつけて残し、古くなった所だけを調べ直す**。

## 1. 答え合わせ（試しの期限が来たら）
「〇〇さんの答え合わせをして」「集客の結果を記録して」と言われたら、または試しの「次に見直す日」が来たら行う。

1. 本人の数字を集める（試しで数えたもの。会話・資料・セッションの文字起こしから）
2. 続ける基準・切り替える基準に照らして、経路ごとに「続ける／直してもう一度／切り替える」を決める
3. 当たり外れの理由を1〜2行で書く（調べ方のずれか、本人の条件の読み違いか、実行されなかったか）
4. 記録を実務カードの形で残す（client-case-recorder と同じ「実務カード」フォルダ、1回1枚）

```text
# 実務カード YYYY-MM-DD A様
種類: 集客の答え合わせ
相手: 記号・業種・型（地域型／オンライン個人向け型／法人向け型）
元の調査: 「A様 集客と差別化リサーチ」（調べた日）

## 試したことと結果
- 経路: 試したこと → 数えたもの（期間）→ 続ける / 直してもう一度 / 切り替える

## 当たり外れの理由
- 

## スキルへのヒント
- 関係するスキル: client-market-strategy
- 内容: （1回だけの話は「候補」止まり）
```
名前・金額の扱いは client-case-recorder と同じ（名前は記号、売上は幅）。

## 2. 調べ直しの合図
次のどれかが出たら調べ直す。
- 前回の調査から3か月たった（変わりやすい項目の鮮度が切れる）
- 試しの結果が「切り替える」になった、または成果が落ちた
- 新しい競合が出た、価格の相場が動いた
- SNS・ポータル・広告の仕様や手数料が変わった（ai-product-watch の日次レポートで知らせが出た時を含む）
- 本人の条件が変わった（使える時間・広告費・商品・価格・地域）

## 3. 調べ直しのやり方（差分だけ）
1. 前回の成果物を読み、各数字の「調べた日」と research-rules.md の鮮度の目安を照らす
2. 鮮度が切れた項目と、合図に関係する項目だけを調べ直す（全部やり直さない）
3. 変わったことを「前回 → 今回」で並べ、提案を変えるかを決める
4. 成果物は同じドキュメントを更新する：冒頭に「更新日と変わったこと」を1〜3行、表の数字と日付を差し替え、提案が変わった所は理由を書く。前回の版はドキュメントの履歴に残る

## 4. スキル自体の更新
- 月1回の実務カードのまとめで、答え合わせの「当たり外れの理由」が3回以上同じ方向に出たら、本スキルの調べ方・選び方の修正候補にする
- 修正は skill-evolver 経由で行い、採用は砂川さんが決める
- references の調べる場所（research-sources.md）や鮮度の目安は、プラットフォームの変化に合わせて同じ流れで更新する
