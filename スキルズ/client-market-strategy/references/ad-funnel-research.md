# 広告と、広告から先の販売導線の見方

広告は、競合が「誰に・どの悩みで・何を約束して・どこへ連れていくか」がいちばんはっきり出る場所。
業種を問わず有無を確認し、出している競合がいれば優先して読む。ただし全案件で最優先に固定しない（広告を出していない事業者や、紹介が主の市場もある）。

## 見る場所
- Meta広告ライブラリ（Facebook・Instagram）
- Google 広告の透明性センター（検索・YouTube等）
- 検索結果の上部に出る広告（地域名＋業種で検索）
- 広告のリンク先のLP・申込みページ・LINE登録後の流れ（見られる範囲）

多くは Web 検索では開けない。ブラウザが使える時はブラウザで閲覧だけ行う。使えない時は**調査済みとして扱わず**、「確認したいこと」に「どのページで・何を見るか」を書く（砂川さんか本人が画面で確認）。

## 1件ごとに見ること
| 項目 | 記録すること |
|---|---|
| 誰に呼びかけているか | 年代・状況・悩みの段階（例：「病院で手術を勧められた方へ」） |
| 切り口 | どの悩み・願望から入っているか |
| 約束と証拠 | 何を約束し、どんな証拠（実績・お客様の声・資格・数字）を出しているか |
| 表現 | 画像・動画・文章の特徴（顔出し・ビフォーアフター・語り口） |
| 行き先 | 広告から無料相談・診断・講座・商品購入・LINE登録のどれにつなぐか |
| 一貫性 | 広告 → LP → 申込みで、呼びかけ・約束・条件がそろっているか |
| 時期と変化 | 確認できる範囲での掲載開始時期、同時に出している訴求の数、変わってきた方向 |

## 読み方の注意（ここを外さない）
- **広告の掲載や長期運用は、売上・利益・成約率の証明ではない。** 「長く出している＝採算が合っている」とは書かない
- 「売れている人」と書く時は、広告とは別の根拠（販売実績の表示・受講者数・レビュー数・公表された数字など）を示す。確認できなければ「販売成果は未確認」と書く
- 広告表現を真似するためではなく、顧客の課題・比べる基準・販売導線を読み解くために使う
- 煽り・偽の希少性・恐怖の強調など、操作禁止5原則に触れる手法は「観察した事実」として記録するだけで、本人への提案には使わない

## 成果物への書き方
- 「広告・販売導線から確認できた事実」として、見た件数・確認日・対象地域を添えて書く
- 事実（何が表示されていたか）と推論（そこから読み取れる顧客の課題・比較基準）を分ける
- 「見たが見当たらなかった」と「確認できなかった」を書き分ける
  - 見当たらなかった：事実として書く（「〇〇市の整体で、確認した範囲では広告を出している院は2件」など）
  - 確認できなかった（ブラウザが無い・取得を拒否された）：「未確認」と書き、確認すること（どのページで・どの検索語で・何を記録するか）に回す
