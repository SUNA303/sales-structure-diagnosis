## C. 違和感記録（砂川さんの理念の輪郭を逆照射）

> 「砂川さんの直感に合わなそう」な部分の記録。理念の輪郭を逆方向から照らす。
> 方針（仮）はいずれも「核（手法）は採用、トーン（煽り・対決・規模前提）は非採用 or 翻訳」。

- **[違和感-002] ローンチの「7日間で6桁ドル」式の派手な成果強調トーン** → 骨格は採用、煽りトーンは非採用。
- **[違和感-003] PR戦略がテレビ報道番組に強く限定** → 普遍原理のみSNSへ翻訳、媒体固有実務は非採用。
- **[違和感-004] PR戦略のearned media依存** → owned（自前発信）と補完で整理。
- **[違和感-005] ポジショニングの攻撃的・対決的トーン（競合をけなす）** → 差別化原理は採用、けなしは非採用（対決でなく対比）。
- **[違和感-006] ポジショニング「勝ち馬に乗れ」の功利的人間関係観** → 核は採用、道具視トーンは外す。
- **[違和感-007] ポジショニングの大企業・マスマーケ前提** → 普遍原理のみ個人事業へ翻訳。
- **[違和感-008] LTV「デジタルは脇役、リアルが主役」** → 媒体主従は非採用、関係の質的中身はSNSへ翻訳。
- **[違和感-009] LTVの顧客ランク付けトーン** → 段階で捉える核は採用、値踏みトーンは「いま関係のどの段階か」へ翻訳。
- **[違和感-010] LTV「フォーマットで行動を強制」のP** → 仕組みは採用、トーンは「型でやさしく後押し」へ。
- **[違和感-013/014] ブレイクスルーの競争撃破・煽動トーン** → 規律ある実行・独自チャネルは採用、「敵を倒す」は「自分にしかできない場所を創る」へ翻訳。
- **[違和感-015/016] ブレイクスルー第3〜4章の競争撃破・過激ブランディング（リキッド・デス等）** → 同上。
- **[違和感-017] コピー心理トリガー（恐怖/緊急性/強欲/罪悪感）完全版** → 核（感情に届く・損得明確）は採用、急かす/煽る使い方は非採用。L0候補-002の強い傍証。
- **[違和感-018] コピー第31章「買うな」と挑発する逆説ティーザー／侮辱しても売れた** → 好奇心の核は採用、挑発・侮辱・誇張は非採用。
- **[違和感・ブランド] ブランド論の大企業・複数ブランド前提** → 規模を読み替えて適用（一人ブランドに過剰設計しない）。
- **[違和感・ブランド] 垂直拡張（下方/バリュー展開）** → ベーシックを「安いコース」と打ち出すと本体ブランドが薄まるリスク。要確認。
