# 18 未来設計（商談前の見立ての中で、未来から逆算して提案を組む）

商談前の見立て（references/16）の 4〜8 を作る時に開く。
文字起こしとアンケートを要約しただけの提案にしない。本人が言ったことを出発点にして、**本人がまだ言葉にしていない所**まで、事実と筋道で組み立てる。
ここで作るのは仮説。当日、本人に確かめて、本人の言葉に置き換えてから使う。
見立ては手元のメモなので、詰めた言葉（道筋・一本・入口・受け皿・土台・前進の道）で書いてよい。ただし台本へ移す時は、そのまま写さず「何を・誰に・いつ・どうする」の話し言葉に直す（conversation-humanity-layer の references/spoken-check.md）。

## 時間の扱い（最初に読む）

- **相手に聞く・口に出すのは、半年後〜1年後まで。** 本人がイメージしやすい近さで話す
- **その先は、年数を付けずに聞く**（「その先は、どうなっていたいですか」）。出なければ追わない
- 「3年後は」「5年後は」のように、年数を決めて相手に答えさせない。遠い年数はイメージしにくく、答えるために作った言葉になりやすい
- **こちらの視点は、1年より先まで見る。** 見立てには、その先まで続く道筋を【推論】として書く。口に出す時は年数を付けず「その先」と言う
- 本人が自分から言った年数（「長くて3年」など）は、本人の言葉としてそのまま使ってよい

## 0. 出すもの（5つ）と、台本での置き場

| 出すもの | 中身 | 台本での置き場 |
|---|---|---|
| ① 未来の並び | 半年後・1年後と、その先（年数は付けない）。本人の言葉のまま。聞けていない所は空欄 | 冒頭の次「未来を確かめる」／訴求1回目 |
| ② 必要性 | 1年後の数字から逆算した「必要な数」と、今との差 | 「逆算」の画面／論点の一文／訴求3回目 |
| ③ 緊急性 | 時間で見た時に、最初の3ヶ月・半年に要ること | 「時間で見る」の画面／「今じゃない」の切り返し |
| ④ 潜在ニーズ | 本人は言っていないが、本人の事実から筋が通ること。3つ以上 | 現状を聞く段の「本人が気づく質問」／「本当の願い」の画面／訴求2回目 |
| ⑤ 前進の道筋 | 強みの型に合わせた一本の道（方向まで）。相手に話すのは1年後までと「その先」。手元ではもっと先まで見て置く | 中間確認の後／第1候補・第2候補の理由 |

台本では、①〜⑤が入る途中のパートは、流れ（「聞くこと」と「次に進む条件」）と、その下の短い「言い方の例」の両方で渡す。そのため見立ての各項目には、**当日、相手から何が出たら次に進んでよいか**（本人が口にする言葉・答え）を1行ずつ添える。通しの台詞で書くのは、冒頭と、コース決めから訴求・締めまで（salesline-navigator）。

## 1. 材料を広げる（文字起こしとアンケートの外まで見る）

| 材料 | 見る所 | ここから出るもの |
|---|---|---|
| 本人が言ったこと | 文字起こし・アンケート・DM | 未来の言葉・数字・期限。**本人が自分から出した言葉**と、質問に「そうですね」と返しただけの言葉を分ける（後者は温度が低い） |
| 本人が外に出しているもの | 本人の名前・屋号で公開されているプロフィール・投稿・予約ページ・HP・商品と料金 | 言っていることと出しているものの差／本人が当たり前にしている強み |
| 本人が言わなかったこと | 答えが短かった所・話題が変わった所・数字が出なかった所 | 当日確かめること |
| その仕事のお金の入り方 | 本人の商品と料金／業界の公開情報（出典つき） | 逆算の式（§3） |
| お客様の側 | 本人のお客様の年代・状況・これから迎える時期 | 本人がまだ見ていない機会と変化 |
| 時間 | 本人が言った期限・予定／制度・市場の変化（出典つき） | 緊急性（§4） |
| 先に進んだ人の形 | 砂川さんの実データ（匿名事例・受講者の声）。無ければ使わない | 道筋の根拠 |
| 砂川さんの商品でできること | 営業資料の該当枚・アドバンスの中身 | 道筋のどこを一緒にやるか |

- 市場の事実は client-market-strategy の商談前の簡易版（3つまで）。そのうち1つは逆算の式に要る事実、1つは時間の変化の事実に充ててよい
- 無い材料は「不明」のまま、当日確かめることに回す。推測で埋めない

## 2. 未来の並び

- 半年後・1年後・その先を、本人の言葉のまま3行で書く。聞けていない所は空欄にし、当日の質問にする（1年後までは聞く。「その先」は年数を付けずに聞き、出なければ空欄のままでよい）
- 1年後にそれが叶っていたら、毎日どんなふうに過ごしていそうかを本人に話してもらう質問を用意する（出た言葉は訴求でそのまま使う。「平日の一日」とは言わない）
- 「それが叶ったら、何が一番変わりますか」を2回まで聞く質問を用意する。できること／どう感じたいか／誰にどう見られたいか・誰に何を渡したいか、のうち、もう出ているものと、まだ出ていないものをメモする
- 未来の中心が、砂川さんが手伝える仕事の中にあるかを、先に確かめる質問を置く。外にある時は逆算をしない（§7）
- **手元の視点**：本人の「その先」が出ていなくても、こちらは1年より先まで続く形（続けて頼まれる流れ・一人で抱えない形・積み上がるもの）を【推論】として1〜2行書いておく。道筋の「その先」と、アドバンスの理由に使う

## 3. 必要性：1年後の数字から逆算する

手順：①1年後（半年後でもよい。本人がイメージしやすい時点、または本人が言った時点）の数字を1つ（月の収入か、月のお客様の数）→ ②その人の仕事のお金の入り方の式に入れる → ③必要なお客様の数 → ④必要な出会い（相談・体験・問い合わせ）の数 → ⑤今との差。

- 数字は当日、**本人に出してもらう**。こちらは割り算を手伝うだけ。見立てには仮の数字で表を作り、「仮」と書く（口には出さない）
- 1年では届かない大きさの目標（積み上がる型など）は、手元ではその先まで計算しておき、相手とは「1年後にどこまで来ていたいか」の数字で話す
- 年商・月商の目標設計そのものを頼まれた時の詳しい手順は references/13

| 仕事の型 | 式 | 当日聞く数字 |
|---|---|---|
| 1回ごと・通ってもらう（サロン・整体・セラピー・鑑定） | 月の収入 ＝ 月のお客様の数 × 1回の単価 × 月の回数 | 理想の月額／単価／通う回数／新しい方は月に何人／続く割合 |
| 契約・継続（コーチ・コンサル・講師・講座） | 月の収入 ＝ 契約中の人数 × 月あたりの単価 | 理想の月額／1契約の金額と期間／相談から契約になる割合／相談の数 |
| 積み上がる（保険・資産・会員・サブスク） | 月の収入 ＝ 積み上がった残高や会員数 × 続けて入る割合・月額 | 1年後に来ていたい所／お一人あたりの大きさ／続けて入る形／相談から契約になる割合 |
| 法人・研修 | 年の収入 ＝ 社数 × 1社の金額 × 年の回数 | 理想の社数／1社の金額／提案から受注になる割合／提案の数 |
| まだ商品がない・売れたことがない | 最初の1人 → 3人 → 月◯人、の順に置く | いつまでに最初の1人か／誰に声をかけられるか |

差を見せた直後に、**強みを先に言い、足りないものを1つに絞る一文**を置く（§5の強みの型）。
差が小さく出たら大きく見せない。本人が言った「その先」の話か、数字以外の願いに移る。

## 4. 緊急性：時間で見る

使ってよい材料は4つだけ。
1. 本人が言った期限・予定
2. 本人のお客様がこれから迎える時期（本人に聞いて確かめる。「この先、どんな時期に入っていきますか」）
3. 制度・市場の変化の事実（出典つき。調査の範囲どおりに言う）
4. 積み上げに要る時間（1年後から逆に見て、最初の3ヶ月・半年に何ができていれば間に合うか。本人に答えてもらう）

- 締切・残数・「今だけ」・事実にない損失を、緊急性の材料として作らない
- 「今のままで半年・1年たったら、どうなっていきそうですか」は本人に答えてもらう。こちらから結論を言わない。出た言葉は訴求で1回だけ使う

## 5. 潜在ニーズ：5つの見方

仮説は1つずつ「仮説／根拠（本人の言葉・事実）／確かめる質問／当たった時の使い所／外れた時」の5点で書く。3つ以上出す。根拠が本人の一言だけのものは「弱い」と書く。

| 見方 | 探すもの | 例 | 確かめる形 |
|---|---|---|---|
| 言葉の奥 | 言ったゴールの、その先にある願い | 「働かなくても入る収入」→ お客様に届けたいと言っていた生活を、自分にも | 「私には◯◯に聞こえたんですが、どう感じますか」 |
| 言うことと、やっていることの差 | 目標と、行動や条件のずれ。本音は条件の側にあることが多い | 「人数を増やしたい」と言いつつ、少人数・対面に絞っている → 深く話せる場のままでいたい | 「◯人というのは、ちょうどいい人数ですか。本当はもっと、ですか」 |
| 当たり前にしている強み | 本人が流した実績・できていること。足りないものは強みの隣にある | 会えば決まる人 → 足りないのは出会う数だけ | §3の逆算で、本人の数字から出す |
| お客様の側から見る | 本人のお客様に、これから起きること | 今のお客様の家族・次の世代が、探していた層そのものだった | 「今のお客様の◯◯は、どのくらいですか」 |
| 一段上の未来 | 言ったゴールを叶えた人が次に欲しくなるもの／本人が「自分には無理」と置いている所 | 少人数の会の先に、他の講師もいる会・公的な場に呼ばれる立場 | 「その先」として未来の並びに入れて、本人に直してもらう（年数は付けない） |

**強みの型と、道筋の向き**

| 強みの型 | 多い詰まり | 道筋の向き |
|---|---|---|
| 会えば決まる（営業力がある） | 新しい方と出会う数・入口 | 自分が会いに行く形から、人が集まる場・人の場を借りる形へ |
| 人が集まる（発信・集客ができる） | 会った後に決まる流れ・単価・続き方 | 集まった人が次に進む場と、商品の階段へ |
| 技術・専門が深い | 何の専門かが伝わる言葉・商品の形 | 一言で言える看板と、最初に頼みやすい商品へ |
| 紹介が出る・人に好かれる | 紹介が届く範囲・紹介の頼み方 | 紹介してくれる人の層を広げる・紹介されやすい入口へ |
| 実績がまだ無い | 最初の1人 | 一番近い3人から、最初の1件と声をもらう所へ |

強みを「足りない」側に置かない。相手がすでにやっていることは、やっている前提で書く。

## 6. 前進の道筋と、喜ばれる場面

- 道筋は 0〜3ヶ月／3〜6ヶ月／6〜12ヶ月／その先 の4段。「その先」は、手元では1年より先まで見て書く（年数は相手に言わない）。本人の半年後・1年後・その先が、同じ一本の道の上に並ぶ形にする。方向まで。中身（台本・文面・選び方・手順）は契約後（references/16「見せないこと」）
- 第1候補アドバンスの理由は、この道筋を1年でどこまで積むか（その先につながる所まで）で言う。第2候補は、道筋のどこまでを回すコースか・届かない範囲はどこかを1つずつ
- 喜ばれる場面を2〜4つ用意する：①本人が自分で気づく質問 ②その場で持ち帰れるもの（自分の数字で出した逆算／一言／テーマ／声をかける3人 など、その場で本人が書けるもの）③未来が一本の道に並ぶ場面
- 数字の計算を一緒にやる方が伝わる相手には、実演資料（計算の画面／今の流れとこれからの流れ／1年の道筋とその先）を別に作る。営業資料のスライドには足さない

## 7. 外れた時の道（先に決めておく）

| 当日こうだった | どうする |
|---|---|
| 未来の中心が、手伝える仕事の外にある | 逆算はしない。手伝える仕事の方に本人の目的があるかを1問だけ聞き、無ければ無理に提案へ進めない |
| 逆算の差が小さい | 大きく見せない。本人が言った「その先」か、数字以外の願いの方へ移る |
| 仮説が違うと言われた | すぐ引く。「教えてください」で本人の言葉に直し、以降はその言葉を使う |
| 数字を言いにくそう | 金額をやめて人数・件数で聞く。それも出なければ逆算は飛ばし、時間の話へ |
| 1年後や「その先」が出てこない | 追わない。本人が言っている一番近い目標（◯月までに・90日で 等）を起点にして進める |
| 本人が先に結論を言った | こちらの仮説は出さず、本人の言葉を論点の一文に使う |

## 8. 出す前の点検（通らない所だけ直す）

1. 本人は言っていないが本人の事実から筋が通ることが3つ以上あり、それぞれに根拠と確かめる質問がある（文字起こしの要約で終わっていない）
2. 未来が 半年後・1年後・その先 の3行で書けている。空欄は当日の質問になっている。相手に年数（3年後など）を答えさせる質問が入っていない
3. 逆算の式が、その人の仕事のお金の入り方に合っている。数字は本人が出す形になっている
4. 緊急性の材料が、本人の事実か出典つきの事実だけでできている
5. 道筋が強みの型に合っている。強みを足りない側に置いていない。手元の視点（1年より先）が1〜2行ある
6. 外れた時の道が決めてある
7. 喜ばれる場面が2つ以上ある

【事実】【推論】【要確認】を必ず分けて書く。

## 9. 守ること

- 仮説は当てにいくものではなく、確かめるもの。当日は「私にはこう聞こえたのですが」で出し、違えば引く。一つの発言だけで相手の気持ちを決めつけない
- 不安・焦り・罪悪感をこちらから足さない。「このままだとどうなるか」は本人が答える。事実にない損失・架空の事例を作らない
- 感情の言葉は、相手が先に出したものだけを使う
- 未来の言葉・数字は、当日本人が言ったものに置き換えてから、訴求と切り返しに使う
- 成果を約束しない（◯ヶ月で◯万円 等）。道筋は方向として話す
- 健康・家庭・お金の事情は見立てに書かない（時間の条件は書いてよい）

## 10. 実施後に残すこと（次の精度のため）

体験セッションの後、client-case-recorder のカードに次の3点を足す。
1. どの仮説が当たり、どれが外れたか
2. 逆算で本人が出した数字と、その時の反応
3. 結果（進む／進まない）と、決め手・止まった所として本人が言った言葉

当たり外れがたまったら、§5の表の例を実例（匿名）に入れ替える。成約率との関係は、この記録の件数がそろってから見る（件数が少ないうちは仮置き）。

## 見本（初期見本・匿名。実施後の実例に入れ替える）

相手：お金の相談業・業界20年超・紹介と地域のつながりで仕事をしているFさん。

- **一行で**：Fさんは「会えば決まる人」。1年後の「会に5人」と、その先の「働かなくても入る収入」から逆に見ると、足りないのは営業の力ではなく、新しい方と出会う数。今の少人数の会は今のお客様の場なので、新しい方が毎月入ってくる入口を作るのが前進の道
- **未来の並び**：1年後「会に5人」／その先「働かなくても収入を得る」「公的な場に呼ばれる人」（どれも本人の言葉。年数はこちらから付けない）
- **逆算（仮）**：手元では「その先」の収入から、必要な残高 → お一人あたりで割った人数 → 決まる割合で割った相談の数、まで計算しておく【推論】。相手とは「1年後に、新しい方からのご相談が月に何件あったら理想か」と「今は月に何件か」の差で話す【数字は当日本人が出す】
- **時間**：地域の新しい事業がこれから始まる【要確認：時期】／今のお客様は増やす時期から使う・渡す時期へ【本人に聞く】／公的な仕事は信頼を得るまで時間がかかる、と本人が言っている【事実。本人が言った年数はそのまま使える】
- **潜在ニーズ**：①お客様に届けたい生活を、自分にも（根拠：その先の言葉とお客様への言葉が同じ形）②人数を増やすより、深く話せる場でいたい（根拠：参加条件を自分で絞っている）③探していた若い層は、今のお客様の次の世代にいる（根拠：お客様の年代）——どれも当日、質問で確かめる
- **道筋**：0〜3ヶ月 看板の言葉と受け皿／3〜6ヶ月 今の会は残し、新しい方向けの会を別に毎月／6〜12ヶ月 所属している集まりや専門家と一緒に開く／その先 その実績を持って公的な場へ。どの段も、前の段でできたものを使って進む
- **手元の視点**：1年より先は、積み上がった残高から続けて入る収入と、公的な場での実績。口に出す時は年数を付けず「その先」と言う
- **外れた時**：その先の収入の中心が別の仕事の方だった → 逆算は飛ばす
