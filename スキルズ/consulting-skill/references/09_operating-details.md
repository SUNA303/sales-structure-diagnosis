## §B 診断の地図の使い方（本体§4より）

### 診断の地図の使い方

```
1. クライアントの訴え（現象）を聞く
2. 思考OS（§3）で論点に変換する
3. 「論点は ①〜⑦ のどの段にあるか」を特定する
4. その段に対応する層の知見（§6の早見表）を参照して一手を作る
5. 多くの場合、詰まりは一段だけでなく連鎖している
   → 「最上流の詰まり」から手をつける（下流だけ直しても上流が空回りする）
6. ③発信は届いているのに⑥成約に進まない場合、③.5 橋渡し（無料プレゼント）の
   不在／設計不良を疑う（発信→成約の一足飛びが最頻出の漏れ穴）。
7. 「導線の段」（①〜⑦）と併せて「顧客の在庫」を見る（顧客起点マーケティング／西口の5セグ）。
   ロイヤル/一般/離反/認知・未購買/未認知のどこに人が滞留しているかで、詰まりの段の裏取りができる：
   ④認知・未購買（フォロワー・リスト）が大量滞留→③.5〜⑥の詰まり／⑤未認知ばかり→①〜③の詰まり／
   ③離反（卒業・休眠）が積み上がる→⑦の詰まり（sales-skillの休眠リアクティベーションへ）。
```

> **重要な診断原則（論点思考1-3「論点は動く」）**：詰まりの段は固定ではない。
> セッション中に最初の訴えより深い段の詰まりが見えてくる。「論点は進化する」前提で伴走する。

## §H H_入力処理フロー（§3）

1. クライアントの現状（悩み・つまずき・数字）を聞く
   ↓【論点思考】現象と論点を区別する
       「フォロワーが増えない」「DMが来ない」＝現象
       論点＝その人特有のヘソ（誰に向けてか不明／自分語りになっている 等）
   ↓【ジョブ理論】悩みの奥の“進歩＝ジョブ”を見抜く（機能/感情/社会の3層）
       「集客したい」の奥に → 不安からの解放（感情）／できる事業主に見られたい（社会）
2. 論点の仮説を立てる
   ↓【仮説思考】問題発見の仮説。プロービング＝「もしかして◯◯では？」とぶつけて反応で確定
3. 打ち手の仮説を立てる
   ↓【仮説思考】問題解決の仮説。「よい仮説の2条件」を自己チェック（掘下げOK？即実行できる？）
4. 伴走者の言葉で返す
   ↓【共感トーン】努力を肯定 → 次の一歩。「やってみたい」と心が動く提案に
5. 反応を見て仮説を進化させる（伴走の継続）
   ↓【仮説→検証ループ】完璧を待たず、仮で出し、反応で磨く
