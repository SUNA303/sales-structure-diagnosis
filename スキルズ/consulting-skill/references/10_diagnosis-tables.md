### 層0｜③ 刺さる発信・言語化（コピー）

> 出典は2系統：**Adweek（シュガーマン）**＝英語圏の普遍原則／**セールスコピー大全（大橋一慶）**＝日本語・SNS実務の撃ち分け。重複は精緻化、差分のみ追加（整合チェック済み・矛盾なし。references/books/16_book18_sales-copy_extract.md §7）。

| 詰まりのサイン | 引く知見（出典） | 返す一手の型 |
|---|---|---|
| 投稿が読まれない・最後まで読まれない | スリッパリースライド（Adweek 第8章）＋大橋本：キャッチ（第一声）→リード（次の言葉）→ボディ（説得）の3段で“次を読ませる”を設計（大橋本 第6・12・13章） | 「一文目の唯一の仕事は二文目を読ませること。冒頭を短く、抵抗ゼロに。キャッチ→リード→ボディの各段で“次を読ませる”役割を持たせましょう」 |
| 読者が「自分ごと」と感じない | resonate＝相手の現実から始める（Adweek 第7章） | 「読者がすでに感じていることから書き始めて、そこに乗せて運びましょう」 |
| 機能説明ばかりで感情が動かない | 感情で買い論理で正当化（Adweek 第11章） | 「事実の羅列でなく、読者の感情を動かす。決断は感情、後付けがロジック」 |
| 商品の機能を並べている | 商品でなくコンセプトを売る（Adweek 第12章） | 「機能でなく“それが人生に何をもたらすか”を一つのコンセプトで」 |
| 発信ネタが切れた | ネタは発明でなく経験の組み替え（Adweek 第1章）＋大橋本：売れるアイデアは“拾う”もの＝同じ商品で別の売り方・別のターゲットを拾う（大橋本 第1章） | 「新規発明でなく、自分の経験を新しい角度で組み替える。商品の中の“別の売り方・別の相手”を拾えば、新しい売り言葉になります」 |
| 長文は読まれないと思い込んでいる | 長さでなく退屈さが敵（Adweek 第14章） | 「滑り台が効いていれば長さは障害になりません。退屈さだけが敵です」 |
| 大勢に向けて書いている | 一対一の語り（Adweek 第15章）／コアメッセージは一つ（第36章） | 「一人への手紙のように。1回の発信で伝えるメッセージは一つに絞る」 |
| 発信を直しても刺さらない・言い回しばかり気にしている | 訴求（誰に何を言うか）≠表現（どう言うか）。訴求が最上流（大橋本 第1・4章） | 「直すのは言い回しでなく“誰に・何を言うか（訴求）”。訴求が決まればキャッチもボディも自動で決まります。まず訴求を1行で固めましょう」 |
| 同じ発信が誰にも刺さらない・反応がバラつく | 3つのターゲットタイプ＝購入意欲が高い客／検討客／購入意欲が低い客で訴求を変える（大橋本 第3・4章） | 「読み手は“今すぐ客・検討客・まだ知らない客”の3層で、響く訴求が別物です。1投稿で1タイプに絞り、そのタイプの感情から書きましょう」 |
| ベネフィットが思い浮かばない・特徴や機能しか書けない | 「ということはつまり法」で連鎖的に導出（大橋本 第2章） | 「特徴に“ということはつまり？（相手は何が嬉しい？）”を繰り返し、求める未来までたどる。出たベネフィットから、狙うタイプが最も反応する1つを選びましょう」 |
| 投稿が読みにくい・凝った装飾で読まれない | 読みやすさの引き算：KISS／白地に黒文字／装飾しすぎない（大橋本 第18章） | 「凝らないこと。1文を短く、白地に黒文字、装飾は最小に。読みやすさはそれ自体がレスポンスを上げます」 |

> **L0/トーン注意（§8と同じ規範）**：大橋本は心理トリガー（緊急性／ザイガニック効果＝続きが気になる／「●●するな」式の挑発キャッチ）を多用する。
> **核は採用**（続きが気になる・損得を明確化・読み手を絞る）／**煽りトーンは非採用**（嘘の緊急性・嘘の限定・挑発・侮辱）。Adweek第31章「買うな」挑発（違和感-018）と同family。
> 「人気の／話題の／選ばれています／実績」は**実態のある事実の範囲**でのみ使う（candidates.md L0候補-002／I節）。
> **診断順序の補強**：発信の不調はまず「訴求（誰に何を）」を疑い、「表現（言い回し）」は後。これは本体§4「最上流の詰まりから手をつける」「下流だけ直しても空回りする」のコピー版（大橋本「訴求がダメだと売れないコピーを書き続ける」／西口「商品が主・発信は従」と同方向）。
