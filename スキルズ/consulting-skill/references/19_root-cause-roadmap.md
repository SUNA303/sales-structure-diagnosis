# 19 解決の道筋カード（根本原因 → 解決方法 → 解決ステップ）

2ステップの最後（体験セッションにつなぐところ）と、体験セッションの資料を説明するところで、「この人の今の課題とゴールに対して、根本原因は何で、どう解決する方向で、どういう順番で進むか」を**軽く**伝えるための材料。salesline-navigator と two-step-navigator は、台本を作る時にこのカードを必ず取る（無ければ先に作る）。

**問題解決はその場でしない。** 伝えるのは「根本原因・解決の方向・順番」まで。具体的な手順・文面・テンプレート・数字の設計・契約後の中身は話さない（それは体験セッションの中の具体化と、契約後の伴走の役目）。

## いつ作るか
- 2ステップの台本を作る時（アンケート回答と、わかっている範囲の本人の発信から。聞けていないことは「不明」にして、当日の質問にする）
- 体験セッションの台本を作る時（2ステップの記録メモ・アンケート原文から。商談前の見立て（references/16）があればそこから転記する）
- 見立てシート（16）を作った時は、最後にこのカードも付ける

## 材料
- 本人の言葉（アンケート原文・2ステップの記録メモ）と、数字・事実
- 本スキル §4 (C) の詰まりの段の判定
- 本人のゴール（理想・いつまでに）。聞けていなければ「不明」
- 推測で埋めない。推論は【推論】と書く

## カードの形（この順。全部で1枚）
0. **主問題と理想**：本人の言葉のまま1行ずつ（主問題／理想）
1. **根本原因（1つ）**：「〈主問題〉が起きているのは、〈原因〉だから」。根拠は本人の言葉・数字・詰まりの段。原因が複数見えても、いちばん手前の1つに絞る。決めつけない言い方にする（「そこに近いかもしれません」ではなく、根拠のある事実だけを言い切る。根拠が弱ければ「不明」にして質問に回す）
2. **解決方法（方向）**：「〈原因〉を、〈何を変えて〉整えると、〈主問題〉が動く」。1〜2文。方法の種類までで、やり方の手順は書かない
3. **解決ステップ（3段まで）**：段ごとに「何を整えるか」と「整うと何が変わるか」を1行ずつ。順番の理由を1つ付ける（なぜその順か）。期間の目安は、本人が言った期限と、砂川さんの確定済みの事実（コース期間）だけから。無ければ書かない
4. **軽版**（2ステップ用。20〜30秒で言える長さ）：1〜3を3〜4文にまとめる。最後は必ず「ただ、〇〇さんの場合の具体的なところは、体験セッションで一緒に見ます」で終える。**コース名・プログラム名・価格・期間は入れない**
5. **本版の割り当て**（体験セッションの資料用）：根本原因＝S7（構造4つのうち当たるところ）／解決方法＝S14（「やることを増やさない」の当てはめ）／解決ステップ＝S23（「何を変えればいいか・どこまで整えば」の当てはめ）。1か所30〜60秒。新しいスライドは足さない
6. **話さないこと**：具体的な手順・文面・テンプレート・数字の設計・その場の改善案・契約後の中身。聞かれたら「そこは体験の中で一緒に具体化します（または契約後に）」と返す
7. **確かめる質問**：この道筋が当たっているかを本人に聞く1問（「ここまでの話で、近いところはありますか」の形。当てはまらない時の道も1行）

## 守ること
- 本人が話していない課題・損失を作らない。悪い未来は本人の現状の延長だけ
- 他社・既存の支援者を否定しない。事実だけ
- 2ステップでは販売しない。道筋を軽く伝えるのは、本人から「変えたい」「今整理した方がいい」「一緒の方が進みやすい」が出て、接続判定が GREEN になった後だけ（two-step-navigator 10 green）
- 数字は実データと本人の発言だけ（konkyo-check の対象）
- 道筋カードは相手に見せる成果物ではなく、台本の材料。台詞にする時は、見立ての言葉（道筋・一本・入口・受け皿・土台）を写さず、普通の話し言葉にする（conversation-humanity-layer の spoken-check）

## 書き方の型（記入欄）
```
主問題：〈本人の言葉〉
理想　：〈本人の言葉／不明〉
根本原因：〈主問題〉が起きているのは、〈原因〉だから。根拠：〈本人の言葉・数字・詰まりの段〉
解決方法：〈原因〉を、〈何を変えて〉整える
解決ステップ：①〈何を整える→何が変わる〉 ②〈…〉 ③〈…〉／順番の理由：〈…〉
軽版（2ステップ）：〈3〜4文。最後は「具体は体験セッションで」〉
本版（S7／S14／S23）：〈一言ずつ〉
話さないこと：〈この人の場合に特に出しやすい中身〉
確かめる質問：〈1問〉／当てはまらない時：〈1行〉
```
