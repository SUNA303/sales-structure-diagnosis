## 1. 「アイデア」＝独自性×便益の四象限 ★商品・発信・LPの万能点検フレーム

> （出典：顧客起点マーケティング 第1章 図1-1。西口の概念）
> 本書の「アイデア」は思いつきの意味ではなく、**独自性**（他にない・代替が効かない）と
> **便益**（顧客にとって得・嬉しい）を兼ね備えた訴求/商品の核を指す。

```
                 便益あり          便益なし
  独自性あり  【アイデア】      【ギミック】（奇抜なだけ。話題になっても買われない）
  独自性なし  【コモディティ】  【資源破壊】（存在価値なし）
              （良いものだが他と同じ。価格競争へ）
```

### 診断質問（クライアントの商品・投稿・LPに対して）
1. それは顧客にとって何が**得**か、一文で言えるか？（便益）
2. その便益は**そのクライアントからしか**得られないか？　他でも手に入るなら理由ごと言えるか？（独自性）
3. 「面白い／珍しい」だけが取り柄になっていないか？（ギミック判定）
4. 「良いものなのに選ばれない」と本人が言っていないか？（コモディティ＝独自性の欠落サイン）

### 判断ルール
- **コモディティ判定**が出たら、改善対象は発信（③）でなく立ち位置（①）またはオファー（★）。
  → 「より良い」を磨くのでなく独自性を作る。既存の「競合をイレレバントにする」
  （ブランド論）・「細いはしご」（ポジショニング）と同方向で、判定基準として使える。
- **ギミック判定**が出たら、「注目は集まるのに売れない」が現象として出る。便益への接続が処方。

## 2. プロダクトアイデアが主、コミュニケーションアイデアが従 ★診断の優先順位ルール

> （出典：同 第1章。西口の概念）

```
プロダクトアイデア          ＝ 商品・サービスそのものが持つ独自性×便益
コミュニケーションアイデア  ＝ それを伝える発信・広告・投稿の独自性×便益

主従ルール：必ずプロダクトアイデアありき。
・発信がどれだけ面白くても、商品側が弱ければ良くて一過性の売上で終わる。
・発信自体の面白さ（バズ）が便益として受け取られ、商品の便益に紐づかないと購買は起きない。
・プロダクトアイデアが強ければ、発信は「それをストレートに伝える」だけで機能する。
```

### 診断への変換（砂川流）
- 現象「投稿は伸びる（いいね・保存される）のに売れない」
  → 論点候補：コミュニケーションアイデア（③）でなく**プロダクトアイデア（①/★）の弱さ**を疑う。
  発信の上手さが商品の弱さを隠している状態。これは本Skillの大原則
  「最上流の詰まりから手をつける」の理論的裏づけそのもの。
- 逆に「商品は強い（買った人の満足・継続が高い）のに知られていない」
  → 処方は商品いじりでなく、③発信〜③.5橋渡しで「ストレートに伝える」こと。

## 3. N1分析 ★この本の心臓部＝層−1（思考OS）の補強

> （出典：同 序章・第1章・第2章2-3。西口の概念）
> 有効な「アイデア」は、**実在する名前を持つ一人の顧客（N1）を深掘りすること**からしか
> 得られない、というのが本書の中核主張。

### なぜ一人か（理論）
- ブレストから有効案が出ないのは、想定する顧客像に**具体性がない**から。
- **(N=1)×10 ≠ N=10**：一人ずつ10人に深く聞くのと、10人の平均を取るのは別物。
  平均化した瞬間に、行動を左右する深層心理の文脈が消える。
- **実在しないペルソナ／想像のカスタマージャーニーは無効**。役に立たないどころか
  戦略を惑わすリスクすらある。会議室で「うちのお客様はこんな方」と合成した人物像は
  実在しない。その時間で実在のロイヤル顧客一人に徹底的に聞く方がよい。
- 「一人に絞るとニッチになる」は誤り。一人の深層心理から出たアイデアが、同じ構造を持つ
  セグメント全体に効くかは**後から定量で検証**する（→§6）。絞るのは聞く段階だけ。

### N1の選び方（手順）
```
1. 先に顧客の在庫マップ（5セグ／9セグ→§4・§7）で全体を把握する
2. 「どのセグメントの一人に・何を知りたくて聞くのか」を設定してから会う
   例）ロイヤル顧客に「なぜ使い続けるのか／最初のきっかけは何か」
       離反顧客に「何があって離れたのか」
       認知・未購買に「知っているのに買わない理由は何か」
3. ブランド（クライアント）との最初の出会いから現在までを時系列で聞く
   （その場で一緒にカスタマージャーニーを描きながら）
```

### N1インタビューの診断質問テンプレ（クライアントに渡せる形）
- 最初に知ったきっかけは？　そのとき何と出会い、何を感じましたか？
- 買う（申し込む）と決めた瞬間、最後のひと押しは何でしたか？
- 使い続けている（通い続けている）いちばんの理由は？
- その前後で、生活や気持ちに何が変わりましたか？
- もし明日これが無くなったら、代わりに何をしますか？（代替品＝真の競合の発見）

### 最重要の注意ルール：「ロイヤル化理由 ≠ トライアル理由」
> （出典：同 第2章2-3）
```
継続している理由（ロイヤル化理由）と、最初に買った理由（トライアル理由）は
多くの場合、別物。継続客の「続けている理由」をそのまま新規向けの訴求に使っても売れない。
例）シャンプー上位ブランドの愛用者は皆「しっとりさらさら」と答えるが、
    それをそのまま広告にしても初回購買は起きない（独自性がないから）。

→ 砂川流の使い方（LP・発信レビューの判断ルール）：
   「お客様の声」をそのまま訴求に使っているLP/投稿を見たら、
   その声が“続けている理由”か“最初に動いた理由”かを仕分けさせる。
   新規向け訴求に使ってよいのは後者（＋独自性と接続したもの）だけ。
```

## 4. 顧客ピラミッド（5セグマップ） ★顧客の「在庫」を見る地図

> （出典：同 第2章 図2-1・2-2。西口の概念）
> どんな商品の顧客層全体も、たった3つの質問で5層に分類できる。

```
質問はこの3つだけ：
  Q1 そのブランド（人・サービス）を知っているか？
  Q2 買った（使った）ことがあるか？
  Q3 その頻度は？（現在も使っているか）

  ① ロイヤル顧客      （知っている・買った・高頻度/継続中）
  ② 一般顧客          （知っている・買った・低頻度）
  ③ 離反顧客          （知っている・買った・今は使っていない）
  ④ 認知・未購買顧客  （知っているが買ったことがない）
  ⑤ 未認知顧客        （知らない）

※認知は「名前を聞いたことがある」でなく、カテゴリー便益を伴った認知
  （「あなたの分野で知っている人・サービスは？」で名前が挙がるか）。
```

### 砂川流変換（個人ビジネス版5セグ）
```
① ロイヤル ＝ 継続契約・リピート・上位コースのクライアント
② 一般     ＝ 単発購入・低額商品のみのお客様
③ 離反     ＝ 卒業生・休眠顧客（contract終了後フォローが切れている人）
④ 認知・未購買 ＝ フォロワー・リスト登録者・無料プレゼント受領者で未成約の人
⑤ 未認知   ＝ まだ出会っていない市場

→ 顧客の旅（①〜⑦）が「導線の段」の地図なら、5セグは「顧客の在庫」の地図。
  二枚を重ねると診断が立体になる：
  ・④認知・未購買が大量に滞留 → 導線の③.5橋渡し〜⑥成約に詰まり
  ・⑤未認知ばかり → ①立ち位置〜③発信に詰まり
  ・③離反が積み上がっている → ⑦関係維持に詰まり（sales-skillの休眠リアクティベーションへ）
```

### 9:1の法則（パレート分析）と利益の集中
> （出典：同 第2章2-1）
- 購買サイクルを複数回またぐ中長期で見れば、ほぼすべての商品で売上は上位顧客に集中する
  （短期で見ると見えないだけ）。さらに**利益で見ると売上以上に上位集中**していることが多い。
- 実例の構造：上位約1〜2割の顧客が売上の大半と利益のほぼ全部を担い、
  それ以外の層への投資はロイヤル層が生む利益でまかなわれている。
- → 既存の「2:8／1:5／5:25」（LTV最大化＝層3）と同方向。判断ルールとして追加できるのは
  「**利益ベースで見直すと集中はさらに強い**。新規獲得コストをロイヤル層の利益が払えているか」。

### 5つの基本戦略（売上の増やし方は5方向しかない）
> （出典：同 第2章 図2-11）
```
(1) ロイヤル顧客のスーパーロイヤル化（単価×頻度を上げる／上位コースへ）
(2) 一般顧客のロイヤル化
(3) 離反顧客の復帰
(4) 認知・未購買顧客の顧客化
(5) 未認知顧客の顧客化（認知形成から）

→ 診断での使い方：「売上を上げたい」という漠然とした相談を、
  まず「5つのうちどの戦略の話か」に分解してから一手を出す。
  クライアントの労力が(4)(5)（新規）だけに偏り、(1)〜(3)（既存・離反）が
  空白になっているのが個人ビジネスの最頻出パターン。
  (3)離反の復帰は sales-skill の休眠顧客リアクティベーションへ直結。
```

### RFM分析の限界（参考）
- 購買データだけのRFM分析は「今いる顧客」しか見えず、思考が上位2層に集中する。
  離反・認知未購買・未認知への中長期戦略が構造的に抜け落ちる。5セグはそれを補う。

## 5. 行動データ×心理データの両面分析

> （出典：同 第2章2-2。西口の概念）

```
行動データ ＝ 何をしたか（購買履歴・閲覧・DM反応・来店…）
心理データ ＝ なぜそうしたか（認知経路・ブランドイメージ・選好の理由…）

ルール：行動データだけのABテスト改善は
「ゴールポストが見えないままシュートを打ち続ける」のと同じ。
当たっても、なぜ当たったかが分からなければ再現も横展開もできない。
行動の差を見つけたら、必ず心理（理由）を N1 で掘る。
```

### セグメント間ギャップ分析（肌ラボの実例構造）
```
手順：
1. 隣接セグメント（例：ロイヤル vs 一般）の認識の差を探す
2. ロイヤル顧客だけが持っている認識を特定する
   実例：ロイヤル「ベタつき＝保湿されている証拠（だから好き）」
         一般    「ベタつき＝不快（だから増えない）」
3. 仮説：「その認識を一般顧客に提示すればロイヤル化するのでは？」
4. 訴求に変換して小さくテスト → 効けば展開
   実例：「手に頬がくっつくほど“もちもち肌”になる化粧水」→ 化粧水No.1へ

→ 砂川流：クライアントの継続客と単発客に同じ質問をして「認識の差」を探す。
  差こそが訴求の原石。欠点と思っていたこと（ベタつき）が、ロイヤル層には
  価値の証拠だった——という反転は、個人ビジネスでも頻出
  （例：「料金が高い」→ロイヤル層には「本気の人しか来ない環境」の証拠）。
```

## 6. アイデアの再現性確認（N1→検証→投資の順序）

> （出典：同 第2章2-4・第4章。西口の概念）

```
N1から得たアイデアは、まだ「一人に効いた」だけ。投資する前に再現性を確認する：
1. アイデアをコンセプト（誰に・何を・なぜ自分が、の一文）に変換する
2. 対象セグメントに小さく当てて反応を見る（本書では量的コンセプトテスト。
   個人ビジネスでは：投稿1本・ストーリーズアンケート・個別相談での反応・小規模募集）
3. 効いたら集中投資、効かなければ別のN1へ戻る

→ 本Skillの「仮説→検証ループ」（仮説思考）と完全に同型。
  N1分析は仮説の“出どころ”を、コンセプトテストは“検証”を担う。
```

## 7. 9セグマップ ★ロイヤルティの中身を見る（応用編）

> （出典：同 第3章 図3-2・3-3。西口の概念）
> 5セグの横軸（購買行動）に、縦軸「**次回購買意向（ブランド選好）**」を加えて9分割する。

```
縦軸の問い：「次も（競合と並べて）これを選ぶか？」
※単なる好き嫌いやNPS（人に薦めたいか）ではなく、本人の次回購買意向で測る。

積極ロイヤル ＝ よく買う×次も選ぶ（失うリスク低）
消極ロイヤル ＝ よく買うが、次も選ぶとは限らない（失うリスク高）★最重要の発見
積極一般／消極一般、積極離反／消極離反、積極・消極の認知未購買、未認知…の9マス。
```

### スーパーA・Bの例え（消極ロイヤルの正体）
```
家の前にスーパーAしかなければ、誰でもAのロイヤル顧客に見える。
しかし200m先に良いスーパーBができた瞬間、購買は流れる。
＝Aへのロイヤルティは「物理的に近い」だけで、独自性×便益（プロダクトアイデア）が
  あったわけではない。近さ以外はコモディティだった。
EC（Amazon等）が小売から一気に顧客を奪えたのは、この「消極ロイヤル」を
全世界レベルで奪ったから。

→ 砂川流変換（診断ルール）：
  クライアントの売上が「立地」に当たるもの——アルゴリズムの追い風、
  プラットフォームの仕様、たまたまの紹介経路、近所だから——に依存していないか？
  それは努力依存とも構造設計とも違う「環境依存」の売上で、環境が変わると一気に消える。
  処方：積極ロイヤル顧客に「選び続ける理由」を聞き（N1）、その独自性×便益を
  言語化して消極層に提示する＝奪われにくくする。
```

### 販売促進×ブランディングの統合可視化
- 9セグ上で「左→右の移動」＝販売促進の効果（買う人が増える）、
  「下→上の移動」＝ブランディングの効果（次も選ぶ人が増える）。
- ブランディングを“アートの聖域”にせず、「次回も選ばれる度合いの変化」として測れる。
- → 砂川流：「発信は数字（フォロワー・いいね）でなく、**指名で選ばれる度合い**が
  動いているかで評価する」という説明に使える（クライアント向け説明文の型）。

### 代替品リスク
- 真の競合は同業ではなく代替品のことが多い（顧客の時間・財布の中で何と競っているか）。
- N1質問「明日これが無くなったら代わりに何をする？」で代替品を特定する。

## 8. 投資判断・認知形成（中長期の数字ルール）

> （出典：同 第2章2-5・第3章・第4章。西口の概念）

```
■ 投資の制約条件：LTV ＞ 顧客一人あたりの獲得コスト
  （顧客一人が一定期間にもたらす累計利益の範囲内でしか、新規獲得に投資しない）
  ロイヤル層のLTV ＞ 一般層のLTV なので、誰を増やすかで許容コストが変わる。

■ 認知と選好が上がると獲得コストは下がる
  （スマートニュース実例の構造：オフラインで認知・選好を作る→オンライン獲得効率が上がる
   →獲得→収益→再投資、の循環）
  → 個人ビジネス版：発信・実績公開・お客様の変化の物語（＝認知と選好づくり）は、
    個別相談の成約率と紹介率を通じて「獲得コストを下げる投資」として説明できる。

■ キャズムと「認知投資を止めるな」
  新商品は感度の高い層（イノベーター・アーリーアダプター）が先に反応するため、
  初速で「売れた」と勘違いしやすい。マジョリティ層はまだ「認知・未購買／未認知」に
  固まっており、そこへ届く前に認知形成の投資を自分で止めてしまうのが
  「初速は良かったのに2〜3ヶ月（年）目で消える」の正体。
  → 診断ルール：「最初は売れたのに止まった」＝商品が悪化したのではなく、
    感度の高い層を取り切っただけの可能性。処方は値下げでなく、
    マジョリティに届く認知・信頼形成の継続（既存のキャズム理解＝consulting資料と接続）。

■ オーバーラップ分析（競合重複）
  自社顧客が競合の何セグメントにいるか（併用・重複）を見る。
  個人ビジネス版：N1に「他に誰のコンテンツを見ているか／何と比較したか」を聞くだけでも
  立ち位置設計（①）の材料になる。→ 本格的な競合調査は market-research-agent へ。
```
