## 1. 第1章｜売上重視のワナ／良い売上アップ・悪い売上アップ ★砂川さんの貫通テーマと直結

> （出典：良い値決め 第1章「売上重視が、会社を不幸にする犯人だった!」。田中靖浩の概念）

```
本書の出発点：「一生懸命がんばっているのに儲からない」会社の共通点＝『売上重視』。
価格下落時に「売上を増やせ」と号令をかけると、現場は売上のために値下げ→利益が減る。

・良い売上アップ … 利益を増やす売上の増やし方（価格を保つ/上げる）
・悪い売上アップ … 利益を減らす売上の増やし方（値下げで数量を稼ぐ）
  → 売上を「販売価格P × 販売数量Q」に分解して見ないと、両者を見分けられない。

「売上ーコスト＝利益」の引き算式のワナ：
  この式は「販売単価が一定」という非現実的な前提を隠している。価格が動くビジネスでは誤り。
  この式を信じると「売上を増やせば利益も増える」と誤解し、悪い売上アップを生む。

正しい計算は「足し算」：
  (販売単価 − 仕入単価) × 販売数量 ＝ 全体の儲け
  ＝「1個の儲け」× 数量。値下げは大切な「1個の儲け」を薄くする危険な行為。
  → 利益の大きさを決めるのは売上ではなく『値決め』。
```

### 砂川さんへの落とし込み

```

            裏づけられている。クライアントが「売上は増えたのに楽にならない」と言ったら、
            まず売上をP×Qに割って「1個の儲けが薄くなっていないか」を見る。
[for-client] マービン・バウアー（マッキンゼー創業者の一人）の言葉が砂川さんの思考OSと一致：
            「企業が潰れるのは、正しい問いに間違った答えを出すからではなく、間違った問いに正しく答えるから」。
            ＝「売上をどう増やすか」という"間違った問い"に正しく答える愚行。
            砂川さんの「現象でなく論点を解く」（§2 究極原則1）の理論的傍証として使える。
```

> （出典：良い値決め 第2章。DOG＝デジタル/オンライン/グローバル、CAT＝コージー/アナログ/タッチ。田中靖浩の概念）

DOG環境（価格が無料へ向かう環境）の3特徴：

  O（オンライン）：日本中・世界中のライバルと安値競争になる
  G（グローバル）：仕事がコストの安い国に奪われる

最も危険な業界の3条件：
  ① 変動費ゼロのコスト構造（材料費がほぼない）
  ② デジタルと相性が良すぎる（成果物がデータ）
  ③ 数字に弱いライバルが多数（言い値で値下げしてしまう）

DOGと戦わない3ステップ（小さき者の進む道）：
  ① 値下げのメンタルブロックを外す（「安くしないと売れない」は"思い込みの病"）

  ③ 値決めを成功させるマーケ＆心理学を学ぶ（後章の4つの「プラ」）

合言葉：「良いものを、より安く」→「良いものを、より高く」へ転換。
  （ピカソの逸話：3分で描いた肖像画に高額。「私はここまで来るのに一生を費やしている」）

CAT（DOGの正反対＝値下げしなくてよい場所）：
  Cozy（居心地の良さ）／Analog（コピーできない不思議な魅力）／Touch（共感と触れあい）
  → レッドドッグ（血の値下げ競争＝レッド・オーシャン）から、ブルーキャット（共感の場＝ブルー・オーシャン）へ。

## 3. 第3章｜値下げ成功・失敗の条件と MPVF ★「値下げするな」の論拠

> （出典：良い値決め 第3章。マクドナルド100円バーガーのケース。田中靖浩の概念）

```
値下げ戦略が成功する2条件：
  ① 変動費の比率が低いこと（＝固定費体質）……「可能性ハードル」（下げられるかどうか）
  ② 値下げによって販売数量が"大幅に"増えること……「成功ハードル」（本当の難所）

「1個の儲け」＝限界利益。値決め→1個の儲け→積み上げて「全体の儲けMP」→固定費Fを超えた分が利益。
  MP > F（MPVF）になればその差が儲け。MP < F なら赤字。
  → 商売の目的は「売上を増やす」ことではなく「MP > F の状態をつくる」こと。

値下分岐点：値下げした"薄い1個の儲け"を埋めるのに必要な数量増は、想像よりはるかに大きい。
  例）変動費比率40%の商品を30%値下げ→以前と同じ儲けに「2倍（+100%）」売る必要。

販売数量の増加を阻む「3つの壁」（自分・ライバル・顧客）：
  ① 自らのキャパシティの限界（そもそも倍は作れない/さばけない）
  ② ライバルの値下げ追随（安さの優位は一瞬で消える）
  ③ 顧客の消費感情（値下げが心に響くとは限らない。慣れると反応しなくなる）

決定的な区別：
  「物理的な設備」中心のビジネス（ホテル・航空＝空席は安くても売った方がマシ）は値下げOKな場合がある。
  「人間そのもの」が中心のビジネス（マッサージ・講師・デザイナー＝砂川さんのクライアント）は、
  安売り＝"時間の切り売り"であり、キャパシティの限界ゆえ値下げで成功することは構造的に不可能。
  → だから「決して値下げしてはいけない商売」。
```

### 砂川さんへの落とし込み

```
[for-skill] クライアントが「値下げを検討中」と言ったら、3つの壁で即チェック：
            ①倍の数をさばけるか ②ライバルも下げないか ③顧客の心が本当に動くか。
            一つでもNo＝値下げは失敗する。「人間そのものが商品」のクライアントは原則ぜんぶNoになる。
[for-client] 「あなたの商品はあなたの"時間"。安売りは時間の切り売りで、学び直す余白を奪います。
            値下げで増益できるのはホテルや航空のような設備型だけ。あなたは値下げで勝てない側です」。
            → これは「頑張りましょう」型でない、即・値下げを止める具体的判断材料。
```

## 4. 第4章｜値決めの哲学（コスト vs バリュー・プライシング）★立ち位置・発想転換

> （出典：良い値決め 第4章。田中靖浩の概念）

```
・悪い値決め … 「価格の哲学」なく周りに流されて行う値決め
・良い値決め … 「価格の哲学」を心に持って行う値決め
  値決め＝情報・サービス業にとって「自分自身に値段を付ける行為」。安くても高くてもよいが、信念が要る。

コスト・プライシング（日本型）：  コスト ＋ 利益 ＝ 売価   …主人公は"自分"。「良いものを、より安く」
バリュー・プライシング（米国型）：売価 − 利益 ＝ コスト   …主人公は"顧客"。「顧客はいくらなら払うか」から出発

→ 良い値決めの核：値決めの主人公を「自分のコスト」から「顧客の感じる価値」へ移す。
   「はじめに"高く売る"と決めて、そこから逆算してビジネスを見直す」。
   顧客が満足するなら、コストが安くても高く付けてよい。満足しないなら、いくら安くしても買われない。
```

### 砂川さんへの落とし込み

```
[for-skill] 「価格をどう決めているか」を聞き、コスト起点（原価の3倍/相場より少し安く）なら、
            バリュー起点（顧客が払える価値から逆算）へ転換を促す。これは値段の問題でなく"主人公"の問題。
[for-self/client] 大企業の担当者に「予算が少なく少額しか出せません」と言われたときの切り返し（本書より）：
            「こちらは少ない時間で運営しており、高額をいただかないとお伺いできません」。
            → 値引き要求を、時間という事実で受け止める（嘘でなく実態。L0候補-001の範囲）。
⚠️ 連携：「価格をいくらに・どう包むか」の作り込み（特典/保証/ネーミング）は $100M Offers（§7）と concepy へ。
         本書は"出発点を顧客価値に置く"という発想転換までを担う。
```

## 5. 第5章｜顧客満足「高」価格と3つの価格ゾーン／メンタルブロック ★価格診断フレーム

> （出典：良い値決め 第5章。田中靖浩の概念）

```
値決めの3つの価格ゾーン（低→高。それぞれ"自分・ライバル・顧客"に対応）：
  ① コスト回収価格ゾーン … 自分のコストを回収できる帯（主役＝自分）
  ② ライバル価格ゾーン   … 周りがいくらで売っているかの帯（主役＝ライバル）
  ③ 満足「高」価格ゾーン  … 顧客が納得して高くても買う帯（主役＝顧客）
  → 悪い値決め＝①②しか見ない（「コストが回収でき、ライバルより少し安く」）。レッドドッグの戦い。
  → 良い値決め＝③「顧客満足『高』価格」を目指す。

外すべきメンタルブロック2つ：
  ブロック1：「価格はコストをもとに決めねばならない」
  ブロック2：「客は安いほうが喜ぶ」
  → どちらも値上げを封じる思い込み。「顧客満足を"低価格"で」をやめ、「顧客満足を"高価格"で」へ。

まぜプラ（ごちゃまぜプライシング）＝複数の儲けを組み合わせて積む：
  ・バリューセット型：薄い儲けの主役に、厚い儲けの脇役を組み合わせる（ハンバーガー＋ポテト・ジュース）
  ・① ジレット・プライシング：本体を安く手に取らせ、消耗品（替え刃）で長期的に厚く回収
  ・② フリー・プライシング：無料＋厚い有料の組み合わせ（→ FREE/13_book15 の橋渡し段と接続）
  ・③ O2Oプライシング：オンライン＋オフラインの組み合わせ
```

## 6. 第6〜8章｜4つの「プラ」のうち ここプラ・くらプラ・やわプラ ★高価格を実現する技法

> （出典：良い値決め 第6章「ここプラ」/第7章「くらプラ＝アンカリング」/第8章「やわプラ＝損失回避」。田中靖浩の概念）
> ※本書の看板＝4つの「プラ」：**まぜプラ（混ぜる）/ここプラ（言い換える）/くらプラ（比べる）/やわプラ（和らげる）**。

### (a) ここプラ（メッセージで価値の感じ方を変える）

```
・MBTスニーカーを「世界最小のフィットネスジム」と名付け、シューズでなくジムと比べさせて3万円を実現。
・実質値上げ（中身を少し減らす）は、値上げの痛み＝損失を顧客に感じさせずに利益を守る（→やわプラと接続）。
→ 砂川流：商品の"呼び名/比較対象"を変えると、価格の天井が動く。コピー（層0③）・立ち位置（層0①）と接続。
```

### (b) くらプラ（比べさせて選ばせる＝アンカリング） ★立ち位置・差別化と直結

```
アンカリング＝人は何かを「基準」にして他を判断する。「ひとつだけ」では選べず、「くらべる」と選べる。
  例）松竹梅は真ん中（竹）が選ばれる／ダミーの高価格を1つ置くと中位が安く見える。

低価格アンカリング（避けるべき失敗）：
  最初に付けた"安い単価"が基準になり、後から値上げできず苦しむ（デザイナーAさんの報酬下落の真因）。
  → 砂川さんのクライアント（フリーランス/サービス業）が「値上げできない」と言う時、まずこれを疑う。
  対処：安く出すなら「（実態のある）高い定価」を先に立て、「今回だけの特別」として下げる（嘘の定価でなく実態の範囲で）。

高価格を実現する2作戦（操作不要・砂川さんと相性が良い）：
  ① アナザー・アンカリング：別カテゴリーと比べさせる（MBT＝ジムと比較）。
     「自分の商品・職業は何であるか」を定義し直し、比較の場所を変える。→ 砂川さんの立ち位置設計（層0①）と同根。
  ② アンカリング・インポッシブル：「比べられないゾーン」をつくる（会計士×落語家コラボ＝前例なし→主導権）。
     レッドドッグと同じ土俵を降り、ブルー・オーシャンへ。→ 砂川さんの差別化・独自カテゴリーと同根。
```

## 7. 既存知見との整合チェック（$100M Offers＝層2 との重複・矛盾）★HANDOFF必須項目

> 結論：**矛盾なし・相互補強**。担当領域が異なる（価値の積み方 vs 価格の決め方）。

```
■ 重複（同方向＝相互補強）
  ・$100M「値下げは$0までしか下げられない、価値を積んで差を広げる」
    ≒ 良い値決め「悪い値決め＝コストとライバルしか見ない／良い値決め＝顧客満足『高』価格」
  ・$100M「値引きでなく特典で価値を積む」
    ≒ 良い値決め「まぜプラ（薄い儲け＋厚い儲けの組み合わせ）」
  ・$100M「価値方程式（分子↑分母↓）」＝価値の作り方
    ↔ 良い値決め「バリュー・プライシング（顧客価値から逆算）」＝価格の出発点
    → 役割分担：$100M＝"いくら積めるか/どう包むか"、良い値決め＝"どこから/いくらに決めるか・下げると何が壊れるか"

■ 良い値決めが新たに足すもの（$100Mにない/弱い領域）
  1. 「1個の儲け」「MPVF」の数字メカニズム＝なぜ値下げが利益を壊すかの会計的裏づけ（砂川さんの売上構造と一致）
  2. 値下げ成功2条件＋3つの壁＝「人間そのものが商品のクライアントは値下げ不可能」の明確な論拠
  3. 3つの価格ゾーン＋メンタルブロック2つ＝価格が上げられない原因の診断フレーム
  4. 低価格アンカリング＝「最初の安い単価」が値上げを封じる、の真因特定（フリーランス頻出）

■ 矛盾しうる点とその処理
  ・良い値決めの一部技法（メンタル・デコイ/でっち上げ定価/不安をあおる）は操作寄り。
    → 既存の §8 トーン規範・L0候補-001/002 の制約下に置く（核のみ採用・煽りは非採用）。$100Mの希少性・緊急性に
      かけている「実態のある事実の範囲のみ」制約と同じ扱い。よって本体の方針と矛盾しない。
```
