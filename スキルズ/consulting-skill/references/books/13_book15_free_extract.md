## 1. フリーの4類型（第2章「フリー」入門・一覧表より）★最重要フレーム

> （出典：FREE 第2章「日常生活に見られるフリーの分類」一覧表。アンダーソンの概念）
> 本書は「無料」を一括りにせず、お金がどこから回ってくるかで4つに分ける。

```
フリー①：直接的内部相互補助（direct cross-subsidies）
  無料のものは「顧客が何かを買うことを見込んで」配られる。
  例（本書）：アップルストアの無料教室、スポーツクラブの無料体験、無料サンプル 等。
  → 無料の品は“呼び水”で、別の有料品の購入を期待して出している。

フリー②：三者間市場（two-sided / 広告収入でまかなう）
  使う人は無料、別の人（広告主等）が払う。例：無料の電話番号案内、広告つきメディア。

フリー③：フリーミアム（freemium＝無料版と有料版がある）
  基本機能は無料、拡張機能は有料。少数の有料ユーザーが多数の無料ユーザーを支える。
  例（本書）：無料通話アプリの基本無料／有料は携帯への通話、子ども無料／親は有料。

フリー④：非貨幣市場（注目・評判・贈与）
  お金以外（注目・評判・善意）が動機。例：オンライン無料講座、物々交換、寄付運営の美術館。
```

### 砂川さんの無料プレゼントはどれか（マッピング）

```
砂川さんの「無料プレゼント → 個別相談 → 3コース」は、
  フリー①（直接的内部相互補助）× フリー③（フリーミアム）のハイブリッド。

・無料プレゼント = 顧客が“その先の有料（個別相談→コース）を買うことを見込んで”配る呼び水（=①）
・無料の中身（基礎の知見/診断）と、有料の伴走（コース）が地続き（=③のフリーミアム構造）

[for-skill] 診断のとき、まず「あなたの無料プレゼントは“何の購入を見込んだ呼び水”か？」を問う。
            ここが言語化できていない無料プレゼントは、ただの“配って終わり”になり橋にならない。
```

## 2. フリーの心理学｜なぜ「無料」は「格安」より桁違いに強いか（第4章）★橋の動力源

> （出典：FREE 第4章「フリーの心理学」。ダン・アリエリーの実験を引くアンダーソンの概念）

```
本書の核心の一つ：「無料（0円）」は“とても安い価格”ではなく、別の心理カテゴリー。
0円と1円の間には、1円と2円の間とは比べものにならない巨大な溝（＝ペニー・ギャップ）がある。

理由：有料には必ず「損するかも」という判断コスト（＝失う痛みの計算）が伴う。
      無料はその痛みをゼロにする。だから人は無料に不釣り合いなほど強く反応する。
      （本書のフリーミアム論：無料は“リスクなしに試す/確かめる”ことを許す装置でもある）
```

### 砂川さんへの落とし込み

```
[for-skill] 無料プレゼントの正体は「価格を下げる」ことではない。
            “会って確かめる・受け取ることの摩擦をゼロにする”ことで、
            「ちょっと受け取ってみよう／話を聞いてみよう」の最初の一歩を出させる装置。

→ だから 990円や「ワンコイン体験」より、設計の良い“完全無料”の方がリード獲得は伸びやすい
  （ペニー・ギャップ）。ただし「無料 → 個別相談」への橋が設計されていることが前提（§3）。

⚠️ 砂川流の禁則：このペニー・ギャップの引力を、嘘の限定・煽り・依存づくりに使わない。
   引力は“正しい一人に、摩擦なく出会うため”に使う。釣って高額を売りつけるためではない（L0候補・§5）。
```

## 3. フリーミアムの構造｜「無料の95%が有料の5%を支える」（第7〜9章）★回収の設計

> （出典：FREE 第7章「フリーと競争する」・第9章「新しいメディアのビジネスモデル」。アンダーソンの概念）

```
フリーミアムの基本算術：
  無料ユーザーは“コストはかかるが収益は生まない”。有料の少数（しばしば数％）が全体を黒字化する。
  つまり「無料で広く配る」だけでは赤字。“どこで・誰が・何で払うか”を必ずセットで設計する。

本書の含意（橋渡しの設計原則）：
  1. 無料の中身は「ケチらない」。価値が薄い無料は信頼を生まず、有料へ橋がかからない。
  2. 無料 → 有料 の“段差”を設計する（無料で得た成果の自然な続きが有料になっている）。
  3. 「無料で集めた人数」でなく「有料に進んだ率」で評価する。
```

### 砂川さんへの落とし込み（無料プレゼント→個別相談→コースの3点設計）

```
[for-skill] 無料プレゼント設計の自己チェック3点（FREEのフリーミアム論を砂川文脈に変換）：
  ① 呼び水：何の購入（個別相談→どのコース）を見込んだ無料か、言語化できているか。
  ② 段差：無料で得た“最初の成果/気づき”の自然な続きが、個別相談・コースになっているか。
     （無料で「自分の詰まりの正体」が分かる → 続きの設計は伴走でやる、という地続き）
  ③ 指標：DL数でなく「無料受取 → 個別相談予約 → 成約」の通過率で見ているか。

→ ①が空白＝配って終わり。②が空白＝無料で満足され有料に進まない。③が空白＝改善できない。
```

## 4. 背景概念（橋の文脈・参照用）

> （出典：FREE 第5章「安すぎて気にならない」・第11章「ゼロの経済学」・第6章「情報はフリーになりたがる」）

```
・潤沢さの経済学：複製・配布のコストが限りなくゼロに近づくと、情報・コンテンツは無料化へ向かう。
  → 知見・ノウハウ系の無料プレゼント（PDF・動画・診断）は“配布コストほぼゼロ”なので、
    フリーミアム型の呼び水として相性が良い（砂川さんの商材と噛み合う）。
・「情報はフリーになりたがる」：情報は無料化圧力が強い。だから無料プレゼントで“情報”を出し、
  有料側は“情報”でなく「伴走・診断・実装・関係」という複製できない価値に置く（→ §6連携）。
```

## 5. 結晶化候補（candidates.md へ提示。採用判断は砂川さん）★抽出のみ

```
[L0候補] 「無料の引力を“操作”に使わない」
  FREEはペニー・ギャップ（無料の心理的引力）を強力に説くが、砂川さんの共感型・伴走型では
  この引力を煽り・嘘の限定・依存づくりに転用しない。「無料は“摩擦なく正しい一人に出会う”ため」
  という縛りを L0-002 候補として提示する。 → 採用しますか？

[中核概念候補] 「橋渡しの段（無料プレゼント＝出会いの摩擦をゼロにする装置）」
  現行マップの③発信と⑥成約の空白を埋める段として、砂川さん独自の言葉に結晶化できる可能性。
  砂川さんが普段やっている「無料 → 個別相談」の導線そのもの。 → 独自の言葉として整理しますか？

[中核概念候補] 「呼び水・段差・通過率（無料プレゼント設計の3点）」
  FREEのフリーミアム論を砂川文脈に変換したチェックリスト（§3）。本体の自己チェックに昇格候補。

[違和感記録] 「とにかく大量に無料配布せよ」という方向
  FREEは“無料で広く”を志向するが、砂川さんは高単価・少人数・深い伴走モデル。
  大量配布は質の低いリードを集め、共感型の個別相談と相性が悪い恐れ。
  → 砂川さんの場合は「広く配る」でなく「正しい一人を引き寄せ、橋でつなぐ」設計に振る。
     この違和感は、砂川さんの理念の輪郭（量より関係）を逆照射している。
```

## 6. 診断→一手 変換テーブル（SKILL.md §6 への追加提案の素材）

> 層0｜③.5 橋渡し（無料プレゼント設計）。出典はすべて『FREE』。

| 詰まりのサイン | 引く知見（出典：FREE） | 返す一手の型 |
|---|---|---|
| 投稿は頑張っているのに個別相談につながらない | 発信と成約の間に「橋（無料プレゼント）」が無い | 「発信から成約へ一足飛びになっています。間に“受け取る理由＝無料プレゼント”を1つ置きましょう」 |
| 無料プレゼントを配っているが個別相談に進まない | 段差の設計不足（フリーミアム第9章） | 「無料で得た“最初の気づき”の自然な続きが個別相談になっていますか？地続きに繋ぎ直しましょう」 |
| 「ワンコイン体験」等にして反応が鈍い | ペニー・ギャップ（第4章） | 「0円と少額は別カテゴリーです。設計の良い完全無料の方が“最初の一歩”の摩擦はゼロにできます」 |
| 無料の中身を出し惜しみしている | 無料をケチると橋がかからない（第7章） | 「無料はケチらない。価値が薄いと信頼が生まれず、有料へ橋がかかりません」 |
| DL数だけ見て一喜一憂している | 評価指標がずれている（フリーミアム論） | 「DL数でなく“受取→個別相談予約→成約”の通過率で見ましょう。直すべき段がそこで分かります」 |
| この無料プレゼントが何のためか説明できない | 呼び水＝内部相互補助の言語化不足（第2章フリー①） | 「その無料は“何の購入を見込んだ呼び水”ですか？まずそれを一文で言語化しましょう」 |

> **L0/トーン注意**：無料の引力（ペニー・ギャップ）は“正しい一人と摩擦なく出会う”ために使う。
> 嘘の限定・煽り・依存づくりには使わない（砂川さんの共感型・伴走型・L0候補§5）。
