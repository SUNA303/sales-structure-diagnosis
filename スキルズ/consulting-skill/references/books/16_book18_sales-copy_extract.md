# 16_book18｜セールスコピー大全（大橋一慶）抽出 ＝ 層0③ 刺さる発信・言語化

> **位置づけ**：層0③（刺さる発信・言語化／コピー）。既存の 11_book13（Adweek Copywriting Handbook＝シュガーマン）が
> 「英語圏の普遍原則（滑り台・感情・コンセプト）」を担うのに対し、本書は **日本語・SNS実務に寄った“撃ち分けの設計図”** を担う。
> 両者は競合せず相互補強（§7 整合チェック済み・矛盾なし）。
> **本書の背骨**：セールスコピー＝「①売れる提案（＝訴求）を探す」×「②それを魅力的に表現する」。**訴求が最上流**で、訴求がダメなら表現を磨いても売れない。

## 2. 診断質問（このSkillが発信の詰まりを切り分けるために使う）

> 「投稿が刺さらない／反応が出ない」と言われたら、表現の前に**訴求**を疑う。順番が命。

1. **その投稿は“誰に”向けたものですか？**（一人に絞れているか。「みんな」は誰にも刺さらない）
2. **その人はいま、商品をどれくらい知っていますか？**（→ 3タイプ判定：購入意欲が高い／検討中／まだ知らない）
3. **その人が“強く求める未来（ベネフィット）”を1行で言えますか？**（特徴・機能でなく、相手の得たい変化か）
4. **直したいのは「言い回し」ですか、「誰に何を言うか」ですか？**（訴求が未確定なら、表現をいじっても無駄）
5. **その訴求は、商品の中から“拾った”ものですか、ひねり出したものですか？**（同じ商品でも別の売り方・別のターゲットが拾えるか）

## 3. 判断ルール（書籍の核を判断基準化）

### ルールA：訴求が最上流（第1・4章）
- セールスコピー＝「売れる提案（訴求）を探す」＋「魅力的に表現する」の二段。**訴求が決まると、キャッチもリードもボディも訴求を軸に自動的に決まる。**
- ∴ **訴求がダメなら、売れないコピーを書き続けることになる。** → 発信の不調は、まず訴求（誰に何を）を疑い、表現（言い回し）は後。
- 砂川接続：本体「最上流の詰まりから手をつける」「下流だけ直しても空回りする」のコピー版。西口「商品が主・発信は従」とも同方向。

### ルールB：3つのターゲットタイプで撃ち分ける（第3・4章）
読み手は商品への知識・興味で3層に分かれ、**響く訴求が層ごとに違う**。1発信＝1タイプに絞る。
（同じバターでも、フレンチ料理屋＝①／健康志向でマーガリンから乗り換え検討中＝②／隠し味に良いと知らない人＝③、と訴求は全く別になる）

| タイプ | 状態（感情） | 狙える条件 | 訴求の方向 |
|---|---|---|---|
| ①購入意欲が高い客 | 「買いたい」。具体的に探している／既にファンで待っている | ブランド力／強い信頼関係（熱烈なフォロワー・リスト）／超強力なオファーのいずれか | 商品名とオファーをズバッと（迷わせない） |
| ②検討客 | 「どうしようかな／どれにしようかな」。比較している | 圧倒的な差別化要因／他より良いオファー | 「他との違い・これまでとの違い」を語る |
| ③購入意欲が低い客 | 「何か良い方法ないかな」。悩みはあるが商品を知らない | 商品を隠して“すばらしい解決法”として語れるか | 売り込まず、悩みの解決法を語る（ベネフィット起点） |

- 砂川接続：西口の5セグ／9セグと直交一致（①≒見込み・ロイヤル／③≒認知前・未認知）。ジョブ理論の「機能/感情/社会」を“認知段階で”切る道具になる。
- SNS実務：フォロワーの大半が③なのに①向けの「商品名＋オファー」を投げて滑る、が最頻出。タイプを取り違えると訴求ごと外れる。

### ルールC：ベネフィットは「ということはつまり法」で連鎖的に導く（第2章）
- 客が払うのは商品・特徴・メリットそのものでなく、その先の**ベネフィット（強く求める嬉しい未来）**。
- 導出ドリル：特徴／メリットを書き出し、それぞれに「**ということはつまり？**」を繰り返す。出てきたベネフィットにさらに問い続けると、1つの特徴から大量に導ける。
- 選ぶ：出たベネフィットから、**狙うタイプが最も激しく反応する1つ**を選ぶ（全部載せない）。
- 砂川接続：本体「商品でなく進歩から逆算」「奥のジョブを掘る」の、現場で回せる手順版。

### ルールD：売れるアイデアは「生み出す」でなく「拾う」（第1章）
- 同じ商品でも、**別の売り方・別のターゲットを“拾えば”新しい売り言葉になる**（黒いバナナにも新しい売り場がある）。
- ∴「ネタがない／差別化できない」は、商品の中の別の訴求を拾えていないだけのことが多い。
- 砂川接続：Adweek「ネタは発明でなく経験の組み替え（第1章）」の同族。候補-A1（商品でなくコンセプト）とも束ねられる。

### ルールE：一発合格を目指さない・テストで磨く（第6・17章）
- キャッチは一発で当てなくてよい。複数案を出し、スプリットラン等で**反応を見て磨く**のが正攻法（セールスコピーは科学）。
- 砂川接続：本体§2「完璧を待たず仮で出して反応で磨く（仮説→検証ループ）」と完全一致。SNSでは「投稿テスト・ストーリーズアンケート・小規模募集」に翻訳（規模注意）。

### ルールF：読みやすさ自体がレスポンス（第18章）
- KISS（簡潔に）／奇をてらったフォントを使わない／カラフルにしすぎない／白抜きより**白地に黒文字**／行頭と行末を揃える／一文を短く／箇条書き・視覚化。
- 凝った装飾は読みやすさを下げ、結果として読まれない。**読みやすさは“足し算でなく引き算”**。

## 4. 提案テンプレ（クライアントにそのまま渡せる型）

### T1：訴求を1行で固めるテンプレ
「【誰（どのタイプの、どんな状況の一人）】に、【その人が強く求める未来（ベネフィット）】を、【商品（手段）】で届けます」
→ これが埋まらないうちは投稿の言い回しに手をつけない。

### T2：タイプ別キャッチの起点（第8〜11章の核のみ）
- ①向け：商品名＋オファーを具体的に強調（「人気の／話題の／ついに」等は**実態のある事実の範囲で**）。
- ②向け：「これまでとの違い・他との違い」「○○しなくても●●できる」「●●の方に選ばれています（事実のみ）」。
- ③向け：商品名を伏せ、悩みの**すばらしい解決法**として語る（「○○で悩む方へ」）。

### T3：売れるストーリーの骨（W型）（第15章）
日常 → どん底 → どん底で経験したこと → 成功を掴む → 成功の秘訣を公開 → ベネフィット → クロージング。
→ 砂川マップでは層0②「振り幅の法則（PR戦略・落差→上昇）」の**具体テンプレ**。買う気がない③タイプを動かす導入に効く。
（※層0②と重複領域。新規発信より「物語で引き込む」用途で使う）

### T4：ベネフィット導出ワークシート
①特徴・メリットを10個書き出す → ②各々に「ということはつまり？」を3回 → ③出た未来から、狙うタイプが最も反応する1つを選ぶ → ④T1の訴求1行に流し込む。

## 5. チェックリスト（発信レビュー用・層0③）

- [ ] 誰（1タイプ・1状況）に向けたか1行で言えるか
- [ ] その人の知識段階（①/②/③）に訴求が合っているか
- [ ] 特徴・機能でなく、相手が求める未来（ベネフィット）を語っているか
- [ ] 訴求（誰に何を）が先に決まっているか（言い回しから入っていないか）
- [ ] キャッチ＝次（リード）を読ませる仕事をしているか
- [ ] 装飾・フォント・色を盛りすぎていないか（白地に黒文字・一文短く）
- [ ] 限定・緊急・実績は**実態のある事実**だけか（嘘の締切・誇大なしか）← §8／L0候補-002

## 6. 砂川流変換（書籍語 → 砂川さんの現場語。※すべて提示。昇格判断は砂川さん＝candidates.md I節）

| 書籍の言い方 | 砂川さんの現場での言い換え（案） |
|---|---|
| 訴求がダメだと売れないコピーを書き続ける | 「言い回しを直す前に“誰に何を”を決める。ここが最上流の詰まりです」 |
| 3つのターゲットタイプ | 「読み手は“今すぐ客・検討客・まだ知らない客”の3層。1投稿1タイプで」 |
| ということはつまり法 | 「特徴に“で、相手は何が嬉しい？”を繰り返して、求める未来まで掘る」 |
| 売れるアイデアは拾うもの | 「ネタは生み出さなくていい。同じ商品の“別の売り方・別の相手”を拾う」 |
| 一発合格を目指さない | 「仮で出して反応で磨く。投稿テストとストーリーズアンケートで」 |

> **トーン注意（§8／L0候補-002 と同規範）**：本書は心理トリガー（緊急性／ザイガニック効果＝続きが気になる／「●●するな」式の挑発キャッチ）を多用する。
> **核は採用**（続きが気になる・損得を明確化・読み手を絞る）／**煽りトーンは非採用**（嘘の緊急性・嘘の限定・挑発・侮辱）。
> これはAdweek第31章「買うな」挑発（違和感-018）と同family。希少性・実績・「選ばれています」は**実態のある事実の範囲**でのみ使う。

## 7. 既存 11_book13（Adweek／シュガーマン）との重複・矛盾チェック ★必須実施

### (a) 重複 → 新規追加でなく「既存行の精緻化」で対応したもの
| 大橋本の知見 | 既存 Adweek 行（層0③） | 判定・対応 |

| ザイガニック効果／続きを読ませる（第9・10章） | 「好奇心の種（第10章）」（§6 step4）・行A | **重複** → 新規行にせず、トーン注記＋違和感記録のみ |
| 相手の現実・心の声に置きかえる（第8章表現法⑤） | 行B「resonate＝相手の現実から始める（第7章）」 | **重複（原則）** → 新規の「3タイプ別」行が行Bを具体化するので、行Bは保持し新規行で補完 |

### (b) 大橋本ならではの差分 → 新規行として追加（日本語SNS実務）
1. 訴求（誰に何を）≠表現（言い回し）・**訴求が最上流**（Adweekに同等の診断順序なし）
2. **3つのターゲットタイプ別の撃ち分け**（Adweekにこの軸なし。Schwartz認知段階の日本語実務化）
3. ベネフィット導出ドリル「**ということはつまり法**」（Adweekは“コンセプトを売る”止まりで導出手順なし）
4. **読みやすさ・装飾の引き算**（第18章。Adweekは文章のみでレイアウト未カバー）

### (c) 矛盾チェック → 矛盾なし（相互補強）
- 「訴求が最上流」は砂川本体「最上流の詰まりから」「下流だけ直しても空回り」＋西口「商品が主・発信は従」を**補強**。
- 「いきなりペルソナを作るな」（第3章）は西口「実在しないペルソナは無効」（14_book16）と**一致**（先にタイプ→後で“動くペルソナ”）。
- 心理トリガーは§8トーン規範と**緊張**するが、Adweek違和感-017と同じ「核採用・トーン非採用」で解消（新たな矛盾ではない）。

### (d) L0チェック
- 自社↔顧客の二者構造のみ。MLM／ダウンライン／紹介主軸の収益化なし。**L0-001 抵触なし**。
- 心理トリガーは L0候補-002（誠実な訴求のみ・煽り型NG）の射程内 → 核のみ採用。
